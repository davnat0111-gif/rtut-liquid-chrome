# Ртуть — жидкие капли, которые сливаются и преломляют страницу

Сайт вымышленного парфюмерного дома. Восемь капель жидкого металла плавают по экрану, сливаются друг с другом и снова разделяются. Одна капля следует за курсором, а по клику раздувается. В каплях отражается страница и гигантское слово на фоне.

С каждым ароматом меняется материал капель:
- **Ртуть** — зеркальный хром со студийными бликами
- **Нефть** — чёрная жидкость с радужной плёнкой
- **Янтарь** — прозрачная смола, сквозь которую преломляется текст
- **Капли** — стеклянные пузыри

## Как это сделано
- **Рейтрейсинг в фрагментном шейдере:** вся сцена — одна формула расстояния (SDF) из сфер, склеенных функцией smooth-min. Поэтому капли сливаются как настоящая жидкость
- Нормали вычисляются по градиенту SDF, отражения — по процедурному «студийному» окружению, плюс эффект тонкой плёнки (thin-film) для радужности
- Фон страницы рисуется в canvas-текстуру, и шейдер берёт из неё и отражение, и преломление
- Мягкие тени капель на фоне и ambient occlusion
- Материалы плавно перетекают друг в друга при прокрутке
- На телефонах рендер идёт в пониженном разрешении
